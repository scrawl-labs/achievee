# 플래너 (구글 캘린더 스타일) — 설계

> 2026-10-05 개정: "하루 정원" 컨셉을 없애고 구글 캘린더와 비슷한 UI와 기능으로 바꿨다. 이전 설계(월간+일간만, 일정 겹침 금지)는 폐기.

## 목적
나 혼자 쓰는 무료 개인 앱. 구글 캘린더 같은 일정 관리 + 할 일 + 하루 지출 기록.

## 범위
**포함**
- 일간 / 주간 / 월간 뷰, 상단 바(오늘, 이전/다음, 제목, 뷰 전환), 왼쪽 미니 달력과 `만들기` 버튼
- 시간표(일간·주간): 현재 시각 빨간 줄, 처음 열 때 현재 시각 근처로 스크롤
- 일정 만들기: 빈 곳 클릭(1시간) 또는 드래그(15분 단위 범위). 일정 클릭으로 수정/삭제 팝업
- 일정 이동(드래그)과 길이 조절(아래쪽 끝 드래그). 날짜 열을 넘나드는 이동 포함
- 겹치는 일정 허용, 나란히 배치
- 월간: 칸마다 일정 최대 3개 + "+n개"
- 오른쪽 패널 [할 일 | 가계부]: 선택한 날짜 기준. 가계부는 그날 합계와 이번 달 합계
- 반응형: 좁은 화면은 기본 뷰가 일간, 패널은 하단 시트, 미니 달력은 숨김
- 터치 기기에서는 드래그 대신 탭으로 만들고 팝업에서 시간 수정 (스크롤과 충돌 방지)

**제외 (YAGNI)**: 반복 일정, 종일 일정, 캘린더별 색상, 알림, 로그인/다중 사용자, 수입 기록, 통계 차트

## 기술
- Vite + React + TypeScript, Astryx 디자인 시스템(neutral 테마, `src/theme/`)
- 시간표/월간 격자는 Astryx에 없어서 직접 구현(`src/styles/calendar.css`, Astryx 토큰만 사용)
- 저장: localStorage `daily-garden:v1`(기존 데이터 유지), `DataStorage` 인터페이스 뒤로 분리
- 순수 로직(`lib/`, `store/`)은 Vitest TDD, 화면은 브라우저로 확인

## 데이터 모델 (변경 없음)
- Event: id, title, date(YYYY-MM-DD), start(HH:mm), end(HH:mm)  (end 최대 23:59)
- Todo: id, title, done, date
- Expense: id, amount(1원 이상 정수), category, memo, date

## 핵심 로직 (`lib/timegrid.ts`)
- `layoutDay`: 겹치는 일정을 묶음(cluster)으로 나눠 열(col)/열 수(cols) 배정
- `dragSpan`, `moveSpan`, `clampSpan`: 15분 스냅, 최소 15분, 하루 범위(0~23:59) 안으로 제한
- `weekDays`, `eventsByDate`, `minutesToTime`

## 에러 처리
- 저장 데이터 손상/localStorage 차단 시 빈 상태로 복구 (구현됨)
- 빈 제목, 잘못된 시간(끝 ≤ 시작)은 폼에서 메시지 표시
