# 하루 정원 (Daily Garden) — 설계

## 목적
나 혼자 쓰는 무료 개인 앱. 구글캘린더처럼 날짜·시간별 일정을 관리하고, 투두리스트와 하루 지출 기록을 한 곳에서 한다. 유료 앱 대체. 귀여운 디자인.

## 범위
**포함**
- 월간 뷰 + 일간 뷰 캘린더 (일간은 0~24시 시간표, 빈 시간대를 눌러 일정 추가)
- 투두리스트 (날짜별, 완료 체크)
- 가계부 (하루 지출: 금액, 분류, 메모)
- 반응형: 폰과 PC 모두 비슷하게 사용
- 색상 플레이그라운드 패널 (개발용, 톤 조정)

**제외 (YAGNI)**
- 주간 뷰, 일정 반복, 알림, 로그인/다중 사용자, 수입 기록, 통계 차트

## 기술
- Vite + React + TypeScript
- 저장: localStorage. 저장 코드는 `src/storage/` 한 곳에 모아 `Storage` 인터페이스로 분리한다. 나중에 DB(예: Supabase)로 교체할 때 이 구현체만 바꾼다.
- PWA는 후순위 (필요하면 추가)

## 화면 구조
- 폰: 하단 탭 / PC: 좌측 사이드바. 탭은 [캘린더] [할 일] [가계부].
- 캘린더: 월간 격자 → 날짜 탭 → 일간 시간표. 월간 칸에는 그날 일정 수와 지출 합계를 작게 표시.
- 일간 시간표에서 일정 생성/수정/삭제 (제목, 시작/끝 시간).

## 데이터 모델
- Event: id, title, date(YYYY-MM-DD), start(HH:mm), end(HH:mm)
- Todo: id, title, done, date(YYYY-MM-DD)
- Expense: id, amount(정수, 원), category, memo, date(YYYY-MM-DD)

## 디자인: "하루 정원"
참고 글(Railcode)의 방식을 따른다: 테마 하나로 통일, 섹션 간 색 전환, 실시간 색상 조절.
- 하늘색 배경 + 구름, 잔디 초록 포인트, 하단은 흙색
- 할 일을 완료하면 새싹/꽃이 자라는 작은 애니메이션
- 지출은 동전/열매 느낌의 아이콘
- 둥근 모서리, 부드러운 파스텔 톤
- 색은 CSS 변수로 정의하고, 플레이그라운드 패널에서 실시간 조절

## 에러 처리 / 테스트
- localStorage 읽기 실패나 손상된 데이터는 빈 상태로 복구한다.
- 시간 겹침, 끝 시간이 시작보다 빠른 입력은 폼에서 막는다.
- 단위 테스트(Vitest): 저장소, 날짜/시간 유틸, 월간 집계. 화면은 브라우저로 직접 확인한다.
